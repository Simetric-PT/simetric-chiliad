📍 Description

This map adds a small shopping area near the Mount Chiliad cableway, designed to enhance roleplay and bring more life to the area.
It features detailed interiors, multiple shop spaces, and is optimized for smooth performance.

⚙️ Installation
Drag and drop the folder into your server’s resources directory

Add the resource name to your server.cfg:

ensure simetric_chiliad
Restart your server

📌 Features
Realistic mini shopping area
Multiple usable interiors
Optimized for FiveM servers
